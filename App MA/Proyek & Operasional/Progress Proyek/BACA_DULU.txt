SUDAH TERINTEGRASI - BACA INI DULU
====================================

Semua konfigurasi di paket ini sudah otomatis diisi:

1. Backend tunggal: Code_Terpadu.gs (di folder ini) sudah ditempel ke
   satu Google Spreadsheet & Apps Script, dan sudah di-deploy sebagai
   Web App. Code.gs lama di tiap folder modul sudah dihapus karena
   sudah digantikan file ini.

2. URL Web App yang dipakai di SEMUA modul:
   https://script.google.com/macros/s/AKfycbyCZ2_aVvNwb7z1Tr_PVRpFoBAhNRrldOu4HfIddIKVJPffnWhDDagiswIgT0muJm72DA/exec

3. Token rahasia (untuk modul Dokumentasi Proyek & Tim Lapangan):
   - Dokumentasi Proyek : ERP2026_5DXF9CXIBR
   - Tim Lapangan       : ERP2026_FGGZVTU7JX
   (Token ini harus SAMA dengan yang ada di baris TOKEN_DOKUMENTASI
   dan TOKEN_TIM pada Code_Terpadu.gs yang sudah Anda deploy.)

4. Kolom penghubung antar modul: "kodeProyek". Isi field ini dengan
   nilai kolom "Kode" dari Daftar Proyek supaya data Jadwal, Pekerjaan
   Lapangan, Dokumentasi Proyek, dan Tim Lapangan bisa dikaitkan ke
   proyek yang sama. Form HTML belum punya input untuk ini -- perlu
   ditambahkan manual bila Anda ingin memakainya.

5. Progress Proyek tidak punya sheet sendiri -- dia mengambil data
   langsung dari modul "proyek" (sheet Proyek yang sama dengan
   Daftar Proyek), jadi tidak ada data ganda.

6. MENU DIGABUNG: "Daftar Proyek" + "Pengalaman Kerja" = satu menu
   "Daftar Proyek & Pengalaman".
   - Sheet "Proyek" kini punya 8 kolom tambahan: Lokasi, Pemberi Tugas,
     Alamat Pemberi Tugas, No Kontrak, Tanggal Kontrak, Nilai Kontrak,
     Tanggal Selesai Kontrak, Tanggal BA. Nama Paket = Nama proyek,
     Ringkasan Lingkup = Deskripsi.
   - Tombol "Excel" dan "PDF" di menu itu mengunduh daftar pengalaman
     (sesuai filter/pencarian yang sedang tampil) dengan kolom format
     INAPROC: Nama Paket, Lingkup, Lokasi, Pemberi Tugas, Alamat/Telp,
     No & Tanggal Kontrak, Nilai, Tanggal Selesai, Tanggal BA.
   - Menu "Pengalaman Kerja" yang terpisah sudah dihapus dari sidebar.

   LANGKAH UPDATE (wajib):
   a. Tempel ulang Code_Terpadu.gs ke Apps Script, lalu Deploy >
      Manage deployments > Edit > New version > Deploy (URL tetap sama).
   b. Jalankan setupAll() sekali -> kolom baru otomatis ditambahkan
      di sheet Proyek (data lama aman).
   c. Bila sebelumnya sudah mengisi sheet "Pengalaman Kerja", jalankan
      migrasiPengalamanKeProyek() sekali untuk menyalin datanya ke
      sheet Proyek. Sheet lama tidak dihapus.
   d. Upload ulang folder website. Tombol Excel/PDF butuh internet
      (library SheetJS & jsPDF dimuat dari cdnjs).

Tinggal upload folder website ke hosting (GitHub Pages, dll).
Tidak perlu edit config.js lagi -- semua sudah terisi.
