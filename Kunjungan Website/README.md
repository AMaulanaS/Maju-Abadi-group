# Kunjungan Website

Folder ini mengumpulkan berkas untuk fitur monitoring kunjungan website:

- `kunjungan.html` — dashboard monitoring.
- `kunjungan.css` — tampilan dashboard.
- `kunjungan.js` — tracker yang dipanggil dari halaman utama website.
- `kunjungan.gs` — sumber backend Google Apps Script.

Tracker aktif dipanggil dari `index.html`. Jika memindahkan atau mengganti nama berkas di folder ini, perbarui juga referensi pada `index.html`. Alamat lama `kunjungan.html` di root dipertahankan sebagai pengalihan agar tautan/bookmark lama tetap bisa digunakan.
