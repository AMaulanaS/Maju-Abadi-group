Portofolio Proyek

Masukkan nama proyek, kategori, dan foto dokumentasi untuk ditampilkan di landing page.

Foto dapat diunggah langsung dari perangkat (maksimal 6 MB; JPG, PNG, WEBP, atau GIF). File tersimpan di Google Drive pemilik Apps Script dan otomatis dibagikan dengan tautan publik agar dapat tampil di website.
