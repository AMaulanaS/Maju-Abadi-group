# PLTS Residensial

Folder ini mengumpulkan aset pendukung bagian PLTS pada website:

- `plts.css` — gaya tampilan komponen PLTS.
- `plts.js` — data paket, harga, spesifikasi, pilihan wilayah, dan interaksi brosur.
- `Brosur/` — brosur untuk Semarang, Kalimantan, dan Papua.

Bagian HTML PLTS masih berada di `../index.html` karena merupakan bagian dari halaman utama satu halaman (company profile). `index.html` sudah diarahkan ke CSS, JavaScript, dan brosur dalam folder ini.
